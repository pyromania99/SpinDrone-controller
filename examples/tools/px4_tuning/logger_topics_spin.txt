# Spin-ramp logging set for the KakuteH7. Copy to the SD card as
#   /etc/logging/logger_topics.txt   and set SDLOG_PROFILE 0.
# PX4 applies this file AFTER the profile; with profile 0 it is the whole set.
# Format: <topic> <interval_ms> <instance>  (interval 0 = every sample).
# Always give the instance: without it the logger takes all 10 instances,
# 10 slots per line of its 255, and silently drops the end of this list.

# asked ~300 and dropped 45% of the 2026-10-02 log. CPU (armed) tracks
